# Support

| You want to… | Go to |
|---|---|
| Ask a question or discuss an idea | [Discussions](https://github.com/Traky12/castuo-e3-001/discussions) |
| Report that the demo worked or failed for you | [Issue #30](https://github.com/Traky12/castuo-e3-001/issues/30) or the *Reproduction report* form |
| Report a bug | [New issue → Bug report](https://github.com/Traky12/castuo-e3-001/issues/new/choose) |
| Propose a feature | [New issue → Feature request](https://github.com/Traky12/castuo-e3-001/issues/new/choose) |
| Report a vulnerability | [Private security report](https://github.com/Traky12/castuo-e3-001/security/advisories/new), never a public issue |

This is a single-maintainer project maintained in the open. There is no paid support and no service-level agreement. Use synthetic data in every report and never paste private keys, tokens or credentials.
