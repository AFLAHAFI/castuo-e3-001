# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text applies to everyone who takes part in this repository: issues, pull requests, Discussions and reviews.

## In short

- Be respectful and assume good faith. Critique work, not people.
- Harassment, insults, discriminatory language and personal attacks are not accepted.
- Do not publish other people's private information.
- Technical disagreement is welcome; keep it about evidence.

## Reporting

This is a single-maintainer project. To report a conduct problem privately, open a private report through [Security → Report a vulnerability](https://github.com/Traky12/castuo-e3-001/security/advisories/new) with a title starting with `Conduct:`. Only the maintainer can see it. You can also use GitHub's **Report content** option on any comment.

Reports are read by the maintainer, kept confidential and answered within 7 days (a target, not a contractual commitment). If the report concerns the maintainer, use GitHub's **Report content** option so that GitHub reviews it.

## Enforcement

The maintainer may edit or remove content, and warn, temporarily restrict or ban participants, following the enforcement guidelines of the Contributor Covenant 2.1.
