Política de privacidad

Responsable: Gregorio J. Jiménez Bodes · [CORREO].

Al usar la demo no recogemos datos personales.

  • La verificación se hace en tu navegador con WebCrypto. Los ficheros que elijas no se envían a ningún servidor: la política de seguridad de la página solo permite conexiones a su propio origen.
  • No hay registro, cuenta, formularios que envíen datos, analítica ni almacenamiento local de identificadores.
  • La página está alojada en GitHub Pages. Según la documentación de GitHub Pages, GitHub registra y conserva la dirección IP de quien visita la página por motivos de seguridad; ver su declaración de privacidad. Ese registro lo gestiona GitHub, no esta demo.
